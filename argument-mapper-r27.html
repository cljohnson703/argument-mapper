Rich Text

$…$ / $$…$$ math   **bold**   *italic*   ~~strike~~   ==mark==   `code`   [text](url) link   URLs and bare domains auto-link
LaTeX also works bare: \textbf{…} \frac{a}{b} \alpha (plain x^2 still needs $…$). Select text and right-click to link it; right-click a link to open, copy, edit, or unlink it.
Escape formatting — to keep markup as literal text: put \ before any marker (\*not italic\*, and \\ for a literal backslash), or ! immediately before a whole element (!**stays plain**, !http://ex.com for a bare URL that shouldn't link). The escape character is consumed. Untick Rich text in the toolbar to type plain text everywhere — nodes and evaluation comments alike — and to show existing content raw for copying markup out; re-ticking never reformats what was already committed.

Given Premises (Axioms)

G — or Given in the toolbar — marks a premise as taken as self-evident: one that receives no further justification. Given premises show a green tint and a green bar down their inner edge.
This is a property of the premise, not a fourth type, so it sits alongside whatever the box already is — a support, objection or rebuttal keeps its border colour, and an implicit given keeps its dashed border too. It applies per box, so one co-premise can be a given while the one beside it still needs support. Main contentions and notes cannot be given: a contention is the claim being argued for, and a note is an annotation.
The mark is descriptive only — the app will still let you attach children to a given premise, and will not warn you when you do.

Cross-References

Right-click a premise → Add Cross-Reference…, then click the target (Esc cancels). The ↗ badge jumps to the target; right-click it to remove. References follow moves and reorders.

Collaboration

Names sit top right — click for the full roster. Boxes others select wear their colour ring and name tag; your own ring is always blue.
Evaluation notes are threaded comments (status dot ↔ Evaluation Overview). Sign in to attribute them; Review locks structure while keeping statuses and comments editable.
Attribution and Review are cooperative, not security — record the Fingerprint (toolbar) to prove a copy is unaltered. Multi-peer testing: open the map with ?peer=Name to make that tab its own collaborator.

Labels (Complex Mode)

M1S1aO2R1 = 1st rebuttal → 2nd objection → co-premise a of 1st support → main contention 1. Free-floating: @500,300S1.
Letters match the type shortcuts: Support, Objection, Rebuttal, Note, Main contention. Older maps written with P for support still import.

Text Export & String Mode

Export/import the whole map as structured text using complex labels; String Mode edits it live. Cross-references trail one per line as SOURCE > TARGET.
Wrap a label in parentheses to mark that premise implicit (dashed border): (M1S1a): unstated assumption, or in square brackets to mark it given (green): [M1S1a]: taken as self-evident. The two nest — ([M1S1a]) is an implicit given. Main contentions and notes are never implicit or given, so the marks are ignored there.

Saving

Two different things are called "saving":
Ctrl+S / Save now keeps a copy inside this browser. It survives closing the tab or rebooting, and it is what restores your map when you come back — but it is invisible to you, no backup will capture it, and it does not travel to another browser or computer.
Ctrl+Shift+S / Save to File writes a real .json file where you choose. In Chrome and Edge the map then stays linked to that file: from that point Ctrl+Shift+S and Autosave write straight to it with no dialog, exactly like a desktop program — the indicator top-right names the file. Other browsers (Firefox, Safari) download a copy each time instead.
Until you save to a file, the indicator says “Saved in browser only”. Each map gets its own slot, so starting a new map never overwrites the last one — Recent Maps… lists everything stored here and switches between them. The browser keeps the most recent dozen.

Your data

Used on your own — including the downloaded file — this app never sends anything anywhere: your maps stay in this browser (and in files you save). No account, no tracking, no analytics.
Only if you share a map does anything leave your device: the map itself, plus the Google display names of the people in it, are stored in a Google Firebase database so collaborators can see each other's edits. Signing in happens in Google's own window — this app never sees your password, and your email address is not shown to other collaborators. The owner can remove members or delete the map at any time.
Google sign-in cannot run from a file opened directly off your disk, so the downloaded copy is for solo/offline use; sharing requires opening the app from its web address.
