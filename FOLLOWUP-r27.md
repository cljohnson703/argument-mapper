# Language and interface follow-up

The common qualification frames now share parsing for three source positions: `FRAME that C from Q`, `From Q, FRAME that C`, and `FRAME from Q that C`. The regression matrix covers active we/one and impersonal passive forms, contracted and expanded negatives, and straight/curly single/double quotations. Added verbs include determine, establish, ascertain, show, prove and demonstrate in their corresponding active/passive forms.

`From Q, we cannot rule out that P` expresses failure of Q to establish not-P. Its quoted premises remain explicit, and it retains the warrant-target behavior. It is not the same as failure to establish P. A nested `that C follows from Q` construction under `it is not necessarily the case` now requires the complete conclusion C to be quoted. `Not necessarily true` retains the existing ambiguity treatment; positive necessity is not erased or equated with conclusion.

The cross-reference badge is horizontally centered in a reserved bottom area. The text's extra bottom margin has been removed, and the badge is raised 1.5px to compensate for the last line's font leading (9.5px from the inner bottom border). Deductive has a blue active state. SVG/PNG export includes visible inference tags and contention assessments and expands the export bounds to contain them.

The color key is in Help, the File controls use three columns in the side panel, and Breadth shares a row with Depth where space permits. Original button heights and 8px spacing are preserved. Scrolling remains available on short viewports or with Advanced expanded; browser viewport fit has not been visually verified. Context labels are Add Premise, Left co-premise, Right co-premise, and Parent.

PhilMaps was inspected as a visual reference. An optional narrow icon rail with accessible names and shortcut tooltips would be a possible later change, subject to the user's approval; it is not part of this update.

Validation: all 47 regression suites passed across the full run and targeted reruns after fixes; the rebuilt public app passed its 21 smoke checks. The follow-up suite includes 897 phrase/UI/export checks and the nested-quantifier suite includes 298 checks. The collaboration suite exposed a timing-dependent viewer refresh problem: merging retained a locally altered viewer copy that could later publish after promotion. Viewer refresh now adopts the shared document, and the complete collaboration suite passes, including backup restoration.
